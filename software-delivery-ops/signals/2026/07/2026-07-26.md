### 信号

该预印本分析 207 个开源 GitHub 项目的 102 万个已审 PR，并将审查讨论表示为人、LLM reviewer 与 AI agent 的交互序列。论文在其样本中报告，agent 发起或多 agent 参与的协作模式与更快审查决策相关，但效率关联未转化为更高审查质量。

### 为什么重要

它为 agentic code review 提供了一个更细的观测单位：协作拓扑而非单一的“是否使用 AI”。交付团队应把 review latency 与合入后质量、返工和人工覆核结果并列度量，避免速度目标侵蚀质量门禁。

### 尚待确认

- 论文的同行评审结果、代码、数据、运行环境、指标定义及可复现性。
- 私有仓库、不同语言栈和不同风险变更中是否存在相同关联。
- 审查质量的操作化定义能否覆盖合入后的缺陷逃逸与安全风险。
