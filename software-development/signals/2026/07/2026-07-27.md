### 信号

Simon Willison 转述的一项调查称，部分低价 LLM token 中转服务会聚合来源不透明的上游额度，再通过 OpenAI-compatible gateway 向开发者转售。该材料把凭证滥用、模型替换、请求数据处理和异常账单连接为同一类开发基础设施风险。

### 证据边界

当前只有 P0 个人来源的二手完整转述；未独立核验具体中转商、额度来源、市场规模或欺诈比例，因此不把转述中的个案路径写成普遍事实。

### 为什么重要

coding agent 会持续消耗模型额度并接触源码、工具权限和凭证。若团队只验证 API 兼容性而不验证上游授权、模型身份、数据处理和预算隔离，低价接入可能把供应链、隐私与成本风险同时带入研发流程。

### 后续观察

- 寻找原始调查方法和可复核样本。
- 关注模型厂商对凭证转售、试用额度滥用和异常计费的正式披露。
- 观察是否出现独立研究验证模型替换或请求留存行为。
